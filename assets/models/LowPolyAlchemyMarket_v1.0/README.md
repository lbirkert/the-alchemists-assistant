# Low Poly Alchemy Market Pack (Free)
by reodesuxz

27 low poly fantasy alchemy market props: potions, cauldron, apothecary furniture, market stalls, ingredients.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Alchemy_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 2590 triangles for all 27 models (30-276 tris each)
- Flat-shaded, simple shared materials (no textures needed)
- Real-world scale in metres, pivot at the base centre
